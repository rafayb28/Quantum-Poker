# Contributing to Quantum Poker

This project explores quantum game theory and quantum computing applications.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/yourusername/Quantum-Poker.git`
3. Create a branch: `git checkout -b feature/your-feature-name`
4. Install dependencies: `pip install -r requirements.txt`

## Development Guidelines

### Code Style

- Follow PEP 8 for Python code
- Use type hints where appropriate
- Add docstrings to functions and classes

### Project Structure

- `src/` - Core game logic and quantum mechanics
- `tests/` - All test files
- `examples/` - Example usage and demos
- `docs/` - Documentation files

### Testing

- Add tests for new features in `tests/`
- Run tests before submitting PR: `python tests/test_quantum.py`

### Commit Messages

Use clear, descriptive commit messages:
- `feat: Add quantum teleportation option`
- `fix: Handle invalid card measurements`
- `docs: Update API documentation`
- `test: Add entanglement validation tests`

## Areas for Contribution

### High Priority
- Implement betting rounds (fold/check/call/raise)
- Add hand evaluation system (determine winners)
- Complete API integration with game logic
- Add more entanglement options

### Medium Priority
- Improve quantum error handling
- Add more comprehensive tests
- Optimize circuit simulation performance
- Create tutorial mode
